## Threat model

The Worker is a public marketing site. It has no accounts, no editor portal, no payments, and no store. Trust boundary: anyone on the internet can GET a page. There is no authenticated role to spoof and no object to tamper with. A visitor cannot write data. Repudiation does not apply to a business transaction, because this origin records none. Information disclosure is the page itself, which is meant to be public, plus whatever an error document leaks (production hides stacks). Denial of service is one SSR render per request, with no database and no fan-out. Elevation of privilege does not arise: there is no privilege.

Entry points: HTTP through `workers/app.ts` `fetch`, then React Router SSR. Routes are the sitemap list plus `sitemap.xml`. No `action`, no cron, no queue, no email handler, no MCP server, no webhook. Deploy is a person running `npm run deploy`. The `.claude` hooks run on a developer machine, not on the Worker.
